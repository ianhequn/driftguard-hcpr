# Repository release policy

This repository is organized for algorithm review and reproducible research.

- Datasets, model weights, optimizer states, and raw video frames stay outside
  Git.
- Historical results remain labeled by their original round and protocol.
- New results must not overwrite Round 10/11 artifacts.
- Exact checkpoint recovery is reported separately from new reproduction.
- Public release should be considered only after the manuscript anonymity and
  checkpoint redistribution rights are resolved.
- The current repository does not grant a license to model weights or VSPW.
