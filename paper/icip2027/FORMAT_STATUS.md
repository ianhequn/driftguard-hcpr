# ICIP 2027 Format Status

## Baseline

The official ICIP 2026 Author Kit was used as the available formatting baseline: `spconf.sty`, `IEEEbib.bst`, US Letter, two columns, double-blind review, five technical pages plus an optional references-only sixth page, no page numbers, embedded fonts, and a 100-150 word abstract. The 2027 author kit must be rechecked when the final submission package is published.

Source: https://2026.ieeeicip.org/author-kit/

The 2027 publishing-options page currently states the same five-page technical limit with an optional sixth references-only page:
https://2027.ieeeicip.org/publishing-paper-presentation-options/

## Current draft policy

- `main.tex` is the single manuscript source.
- Blind output suppresses author names, affiliations, acknowledgments, and identifying repository text.
- Publish output uses placeholders until the authors provide the final author list and affiliation.
- Figures are vector PDF assets generated from repository artifacts.
- No page number, header, or footer is added by the manuscript.
- Final 2027 rules, category, deadline, and PDF checker remain TODOs.
